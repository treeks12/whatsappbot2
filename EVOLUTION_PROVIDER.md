# Evolution Provider

The bot v2 talks to Evolution through `app/evolution.py`.

## Supported targets

### Stable fallback

```env
EVOLUTION_API_URL=http://evolution-api:8080
EVOLUTION_API_KEY=...
```

This targets `evoapicloud/evolution-api:v2.3.7`.

### New stack candidate

```env
EVOLUTION_API_URL=http://host.docker.internal:8081
EVOLUTION_API_KEY=<manager-generated-key>
```

This targets the isolated `evoapicloud/evolution-api:2.4.0-rc2` lab.

Evolution `2.4.0+` requires community activation before business endpoints are available. Until activation, `/license/status` returns `inactive` and endpoints like `/instance/fetchInstances` return `503 LICENSE_REQUIRED`.

The key for `EVOLUTION_API_KEY` should be the key generated by the Evolution Manager/licensing flow. In the lab compose, set the same value as `EVOLUTION_24_AUTHENTICATION_API_KEY`.

## Smoke test

From `whatsapp-bot-v2`:

```powershell
$env:EVOLUTION_API_URL='http://localhost:8081'
$env:EVOLUTION_API_KEY='<manager-generated-key>'
python -m app.smoke_evolution
```

The smoke test checks:

- root/version endpoint
- license status
- fetch instances
- create/connect/delete probe instance, only when business endpoints are unlocked
